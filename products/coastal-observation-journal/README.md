# Coastal Observation Journal — Product Candidate 01

**Format:** self-contained print-ready HTML + this source README  
**Audience:** families, teachers, nature clubs and beginner coastal observers  
**Use:** record what you can observe safely from a lawful, stable location. This is an observation activity, not a survival, foraging, fishing, medical or navigation guide.

## Files
- `coastal-observation-journal.html` — three-page A4 worksheet; open in a browser and print/save as PDF.
- This README — scope, use and release checklist.

## Print
1. Open the HTML file in a browser.
2. Choose Print → Save as PDF, A4 paper, scale 100%, backgrounds enabled if desired.
3. Check every page before distribution; browser print dialogs vary.

## Boundaries
Observe from a stable place above the waterline. Do not enter water, climb rocks, approach wildlife, touch unknown organisms, collect specimens, or go beyond barriers for this worksheet. Follow local access rules and posted warnings. Stop if weather, waves, tides, visibility or footing make the location unsafe. Children should remain with a responsible adult.
