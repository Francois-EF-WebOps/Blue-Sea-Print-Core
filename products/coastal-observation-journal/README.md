# Coastal Observation Journal — Product Candidate 01

**Format:** three-page A4 worksheet; editable HTML source, with a separate PDF review draft  
**Audience:** families, teachers, nature clubs and beginner coastal observers  
**Use:** record what can be observed safely from a lawful, stable location. This is an observation activity, not a survival, foraging, fishing, medical or navigation guide.

## Files and production status

- `coastal-observation-journal.html` — editable three-page worksheet source.
- `LEARNING_SPEC.md` — intended learner, outcomes, learning sequence, differentiation and pilot questions.
- This README — product scope, production status, use boundaries and release checklist.
- **PDF review draft v0.1:** generated separately with ReportLab and reviewed on an Oppo Android phone. It is not yet stored in this repository, and its generator/source and dependency instructions are not yet part of the repository. It is therefore a review artifact, not a reproducible repository release.

## PDF production

There are currently two distinct routes; do not treat them as interchangeable or claim that the repository has a reproducible PDF build yet.

1. **Current HTML route:** open `coastal-observation-journal.html` in a browser; choose Print → Save as PDF; select A4 and 100% scale; inspect every page because browser print settings vary.
2. **Review-draft route:** PDF v0.1 was generated separately using ReportLab. The exact generator source and build instructions still need to be added and tested before this can become the controlled production route.

The v0.1 PDF opens on an Oppo Android phone (user-checked). The checkbox outlines appeared greyed out and need stronger contrast in the next revision. Physical printer output has not been verified. Do not mark print QA as passed on the basis of phone viewing alone.

## Boundaries

Observe from a stable place above the waterline. Do not enter water, climb rocks, approach wildlife, touch unknown organisms, collect specimens, or go beyond barriers for this worksheet. Follow local access rules and posted warnings. Stop if weather, waves, tides, visibility or footing make the location unsafe. Children should remain with a responsible adult.
